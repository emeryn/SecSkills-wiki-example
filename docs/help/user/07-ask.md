# Ask the wiki

**Ask the wiki** answers questions in plain language from the pages you can read, and lists the
pages it used as numbered sources.

- Type a question, then **Ask** (or `Ctrl+Enter`). **Stop** interrupts a long answer.
- Follow-up questions keep the last few exchanges as context; **New conversation** starts over.
  Conversations are not saved.
- Only pages you can read are searched: other people's restricted spaces are never used, nor
  quoted, nor listed.
- Answers come from a language model and can be wrong: check important ones against the sources.
- Each person has a daily allowance; the page shows how much is used.
