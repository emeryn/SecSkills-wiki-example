# Editing pages

The editor shows Markdown on the left and the preview on the right.

- `Ctrl+S` saves. Every save creates a revision; add a short message to explain the change.
- Leaving the page with unsaved changes asks for confirmation.
- Link to another page of the space with `[[Page title]]` or `[[Page title|link text]]`. Links to
  pages that do not exist are highlighted.
- **Attachments**: upload images and documents (PDF, Office, text; 10 MB max) below the page, then
  copy their Markdown to embed an image.
- Images from other websites are not loaded, and HTML in Markdown is shown as text.

## Someone else saved first

If another person saved the page while you were editing, the editor shows both versions. Keep
yours or take theirs, merge by hand if needed, then save again.
